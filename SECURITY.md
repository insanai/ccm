# Security reports

We maintain the latest published beta. Report a suspected vulnerability through [GitHub private vulnerability reporting](https://github.com/insanai/ccm/security/advisories/new).

Include the CCM version, operating system, a small reproduction, and the expected impact. For a malicious-source or HTML-report issue, include the smallest source filename or content that demonstrates it.

Counting discrepancies and ordinary usability defects belong in the public bug form. CCM's development cost scenarios are estimates; their calibration limits are explained in the book.
