CCM: Code, Change, and Confidence
=================================

.. only:: html

   A book about the things we can count, the changes we must understand, and the evidence we need before accepting them.

   We begin with a source tree and end with a defensible explanation of a change.
   The running checkout example keeps the algorithms, mathematical claims, and economic assumptions attached to an executable result.
   We can follow the story from the beginning or use the contents to return to a particular argument.
